## Setup

Run this once, from the repo root:

`uv venv && uv pip install -e ".[dev]"`

It does not need activating. Everything below calls `.venv/bin/python` and `.venv/bin/ruff`
directly, which is what you want when each command runs in its own shell.

The dashboard under `web/` is a **separate** install and is only needed if the issue changes
files in `web/`. Then, and only then: `cd web && npm ci`. Skip it otherwise — it is minutes of
wall clock for nothing.

## Verify

The two gates CI runs on your pull request, and only these:

    .venv/bin/ruff check --select F,E9 control telemetry
    for f in control/*_test.py telemetry/*_test.py; do .venv/bin/python -m "$(echo "${f%.py}" | tr / .)"; done

Both are fast. Run them before opening the pull request, not after.

If you changed anything under `web/`, also run `cd web && npm run build` — a TypeScript error
there is a broken dashboard that no Python test will catch.

## What is worth knowing before you start

- Tests are plain modules with a `__main__` block. There is no pytest and no test runner. Add
  one at `control/<thing>_test.py` or `telemetry/<thing>_test.py` and the loop above picks it
  up by existing; nothing registers it anywhere. Follow the shape of the file beside it, and
  do not introduce a test framework.

- `ruff check` **in full** reports pre-existing style findings, so it is red on arrival and is
  not the gate. `--select F,E9` is. Do not widen the selection, and do not go fixing what it
  does not flag — that is someone else's backlog, not this issue.

- Layout: `control/` is the FastAPI control plane (aiosqlite for state, one module per
  concern), `telemetry/` is run instrumentation, `web/` is the Vite + React + Tailwind
  dashboard, `scripts/` is bash for provisioning boxes and goldens. Read `control/README.md`
  before changing anything under `control/` — it holds rules the module layout does not show,
  including which things the control plane is forbidden to do.

- Do not run an end-to-end or browser suite, and do not install browsers. CI covers that on
  your pull request.
